## 2024-05-24 - DOM Traversal Optimization for UI Routing
**Learning:** In a single-page application using class toggling for routing (e.g., `goTo(id)`), calling `document.querySelectorAll('.screen')` on every route change is an inefficient O(N) DOM operation, and avoiding updating DOM when navigating to an already active screen avoids unnecessary repaints.
**Action:** Cache the active screen in a local variable (e.g., `_activeScreen`), and add an early return to prevent resetting the state if the target screen is already active. This reduces DOM traversal and class manipulation, yielding measurable performance improvements.
